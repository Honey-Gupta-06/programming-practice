# Student Performance Analysis

## 📊 About

A Python data analysis project that analyzes student academic performance using Pandas and Matplotlib.

## 🛠️ Technologies

- Python
- Pandas
- Matplotlib
- CSV

## 📌 Features

- Analyze student marks
- Calculate total and percentage
- Find top-performing students
- Find average marks
- Analyze performance by course
- Analyze performance by city
- Create data visualizations

## 📈 Visualizations

- Average percentage by course
- Percentage distribution
- Math vs Computer marks

## ▶️ How to Run

Install dependencies:

```bash
pip install pandas matplotlib
